**Turn rough thoughts into clear text.**

**Inklet**은 입력하거나 붙여 넣거나 말로 한 생각을, 지금 쓰고 있는 앱을 떠나지 않고 명확한 글로 바꿔 주는 macOS 글쓰기 도우미입니다.

전역 단축키로 글쓰기 팝오버를 열고, 하나의 편집 가능한 원문 초안에 입력하거나 붙여 넣거나 받아쓰면 됩니다. 실시간 받아쓰기는 글쓰기 도우미 안에서만 이루어지므로, 변환하거나 삽입하기 전에 받아쓴 내용을 검토할 수 있습니다. Apple 실리콘 Mac에서는 새로 설치하면 음성을 이 Mac에서 인식하므로, 목소리가 Mac 밖으로 나가지 않습니다.

## 설치

Inklet은 GitHub Releases를 통해서만 배포됩니다. [GitHub Releases](https://github.com/wanming/Inklet/releases)에서 서명 및 공증된 최신 DMG를 내려받아 열고, Inklet을 `/Applications`에 복사하세요.

아래 설치 스크립트를 사용할 수도 있습니다. 이 스크립트는 최신 GitHub Releases DMG와 체크섬을 내려받아 DMG 구조, 체크섬, Gatekeeper 승인, 번들 식별자, Hardened Runtime, 유효 entitlements, 앱 서명을 검증한 다음 Inklet을 `/Applications`에 복사합니다.

```bash
curl -fsSL https://raw.githubusercontent.com/wanming/Inklet/main/scripts/install.sh | bash
```

## 업데이트

Inklet은 GitHub Releases만을 업데이트 소스로 사용합니다. 정식 빌드는 약 24시간마다 한 번 GitHub에서 최신 안정 릴리스의 공개 메타데이터를 확인합니다. 해당 릴리스에 `Inklet.dmg`가 업로드된 뒤에만 업데이트를 알리며, **GitHub에서 보기**를 누르면 그 릴리스 페이지가 열립니다. Inklet은 업데이트를 자동으로 내려받거나 설치하지 않습니다.

정식 앱과 Inklet Local 모두 앱 메뉴의 **업데이트 확인…**으로 직접 확인할 수 있습니다. Inklet Local은 자동 확인을 예약하지 않습니다. 자동 확인이 실패하면 아무것도 표시하지 않고, 직접 확인이 실패하면 **재시도**를 제공합니다. 글쓰기, 받아쓰기, 선택 동작, 데이터 이전, 모달 창, 열린 메뉴 때문에 Inklet이 사용 중이면 자동 업데이트 알림은 앱이 쉬고 있을 때까지 기다립니다.

업데이트 후 새 버전을 처음 실행하면, Inklet이 쉬고 있을 때 짧은 **새로운 기능** 창이 한 번 표시되며 사용 중인 앱의 포커스를 빼앗지 않습니다. 새로 설치했을 때나 환영 안내가 열려 있을 때는 나타나지 않습니다. 메뉴 막대 메뉴의 **업데이트 기록**에는 모든 릴리스가 나열되고, 실행 중인 버전이 강조 표시됩니다.

## 처음 설정하기

1. 응용 프로그램 폴더에서 Inklet을 엽니다. 소스에서 빌드한 경우 저장소 루트에서 `scripts/run-local-app.sh`를 실행한 뒤 `/Applications/Inklet Local.app`을 사용하세요.
2. 메뉴 막대의 Inklet 아이콘을 클릭하고 **설정**을 엽니다.
3. macOS가 요청하면 손쉬운 사용 권한을 허용합니다. Inklet은 이 하나의 범용 권한으로 선택한 텍스트를 읽고, 설정된 복사 대체 경로를 실행하고, 이전 앱으로 포커스를 되돌리고, 확인한 결과를 붙여 넣습니다. 시스템 설정이 열려 있는 동안 Inklet은 백그라운드에 머물며, 닫으면 **일반** 설정으로 돌아옵니다.
4. 새로 설치했을 때, 그리고 이 버전으로 업데이트한 뒤 한 번, 환영 안내가 인터페이스 언어(새 설치는 시스템 언어를 따름), 손쉬운 사용 권한, 글쓰기 모델, 실시간 받아쓰기용 마이크, Inklet 열기 및 받아쓰기 단축키를 차례로 안내합니다. Apple 실리콘 Mac에서는 **내장**과 권장 모델을 제안하며, 그대로 두면 백그라운드에서 내려받습니다. 글쓰기 팝오버에 진행 상황이 표시되고, 다 받으면 오프라인에서도 작동합니다. 클라우드 제공업체를 쓰려면 **일반**에서 제공업체를 고르고 API 키를 입력하세요. Intel Mac의 기본값인 OpenAI를 쓰면 키 하나로 글쓰기, 실시간 받아쓰기, 선택 텍스트 번역, 발음을 모두 처리합니다. 다른 제공업체를 선택하면 글쓰기와 선택 텍스트 번역은 그 제공업체를 사용하지만, 발음과 OpenAI를 선택했을 때의 받아쓰기에는 별도의 선택 입력란에 OpenAI API 키가 필요합니다. 키 없이 Mac에서 글쓰기와 번역을 실행하려면 **내장**을 선택하고 모델을 내려받거나, 이미 사용 중이라면 **Ollama** 또는 **LM Studio**를 선택하세요([로컬 모델](#로컬-모델) 참고).
5. **글쓰기 도우미**에서 모델, 글쓰기 단축키, 생성 설정, 프롬프트 모드를 설정합니다. **실시간 받아쓰기**에는 별도의 설정 페이지가 있어, 켜고 끄기, 음성 인식에 **이 Mac**과 **OpenAI** 중 무엇을 쓸지, 길게 누르기 단축키와 마이크를 고를 수 있습니다. Apple 실리콘 Mac의 새 설치에서는 **이 Mac**을 사용하며, 환영 안내에서 받아쓰기를 켜면 음성 모델을 내려받습니다. 기존 설정은 직접 바꾸기 전까지 OpenAI를 그대로 사용합니다. OpenAI를 쓸 때 **고급 받아쓰기**에서는 복구 모델만 바꿀 수 있고, 복구 엔드포인트는 편집할 수 없습니다. 실시간 모델은 Inklet이 고정합니다.
6. 선택 사항: **선택 도우미**에서 번역 언어, **강제 선택** 모드, AI 발음 음성과 속도를 설정하고, 설정에서 음성을 미리 들어 볼 수 있습니다.
7. 받아쓰기 단축키를 처음으로 유효하게 길게 누를 때 마이크 권한을 허용합니다. Inklet을 열거나, 설정을 보거나, 원문 편집기 밖에서 단축키를 누르는 것만으로는 권한을 요청하지 않습니다.

## 일상적인 사용

텍스트 흐름:

1. 다른 앱에서 텍스트 필드에 포커스를 둡니다.
2. `Option+Space`를 누릅니다.
3. 프롬프트 모드를 퍼지 검색하고(예: `영어`로 `쉽고 올바른 영어로`를 찾을 수 있음), `Up` / `Down`으로 강조한 뒤 `Tab` 또는 `Enter`로 모드를 확정합니다.
4. 초안을 입력하거나 붙여 넣습니다.
5. `Enter`를 눌러 변환합니다. 결과는 생성되는 대로 표시되며, `Escape`로 멈출 수 있습니다.
6. `Enter`를 한 번 더 누르면 결과를 삽입합니다. 대신 복사하려면 `Shift+Command+C`를 누르거나 결과의 복사 버튼을 클릭하세요.

받아쓰기 흐름:

1. `Option+Space`로 **글쓰기 도우미를 엽니다**.
2. **프롬프트 모드를 확정합니다**. 모드 선택기와 결과 편집기에서는 받아쓸 수 없습니다.
3. **원문 초안에 커서를 두거나, 바꿀 텍스트를 선택합니다.** 받아쓰기는 커서 위치에 삽입되거나 선택 영역을 대체합니다.
4. **설정한 받아쓰기 단축키를 길게 누른 채**(기본값은 오른쪽 Option) 평소처럼 말하면 초안이 그 자리에서 업데이트됩니다. 짧게 누르면 아무 일도 일어나지 않습니다. 실시간 연결이 끊어지면 계속 누른 채로 말하세요. Inklet이 임시 복구 녹음 하나를 보관합니다.
5. **손을 떼면 받아쓰기가 확정됩니다**. **이 Mac**을 쓰면 복구도 Mac에서 받아씁니다. OpenAI를 쓰는 경우 복구가 필요하면, Inklet은 실시간 받아쓰기에 쓰는 기존 OpenAI API 키로 `https://api.openai.com/v1/audio/transcriptions`에 요청을 한 번만 보냅니다. 임시 녹음은 대체 요청이 실제로 시작되기 전까지 로컬에만 있고, 최대 한 번만 업로드되며, 세션이 끝나면 삭제됩니다.
6. 받아쓴 초안을 검토하고 편집합니다. 받아쓰기만으로는 프롬프트 모드가 실행되거나 다른 앱에 텍스트가 삽입되지 않습니다.
7. **준비가 되면 Return을 눌러** 확정한 프롬프트 모드를 실행합니다. 결과를 삽입하고 싶을 때만 Return을 한 번 더 누릅니다.

받아쓰기 단축키는 원문 편집기 안에서만 작동하며 길게 누르기 전용입니다. **설정** → **실시간 받아쓰기**에서 보조 키를 오른쪽 Command, 왼쪽 Option, 왼쪽 Command로 바꾸거나 받아쓰기를 완전히 끌 수 있습니다. Escape, 포커스 잃음, 팝오버 닫기, 다른 원문 세션 열기는 받아쓰기를 취소하고 원래 초안으로 되돌립니다.

## 주요 기능

- macOS 전역 단축키로 열립니다. 기본값은 `Option+Space`입니다.
- 글쓰기 도우미 원문 편집기가 활성 상태일 때 보조 키 단축키를 누르고 있으면 실시간 받아쓰기가 초안에 바로 입력됩니다. 기본값은 오른쪽 Option입니다.
- 다른 Mac 앱에서 텍스트를 선택하고 잠시 멈추면 선택 동작이 나타납니다. EasyDict 스타일의 선택 텍스트 읽기, 빠른 번역, 사용자 지정 가능한 **번역** 프롬프트, AI 발음을 제공하며, 번역 결과 창은 크기를 조절할 수 있고 마지막 크기를 기억합니다. 반복되는 번역은 7일 동안 로컬에 캐시됩니다.
- 페이지 전체를 실수로 선택했을 때 실행되지 않도록 1,500자를 넘는 선택 텍스트는 무시합니다.
- 선택한 텍스트를 바로 읽어 주고, 번역 결과에서 원문과 번역문을 모두 재생할 수 있습니다.
- **설정** › **선택 도우미** › **메뉴 버튼**에서 선택 메뉴에 표시할 버튼과 순서를 고를 수 있습니다. **번역**, **발음**, 그리고 어떤 프롬프트 모드든 버튼으로 만들 수 있으며, 한 번에 최대 네 개가 표시되고 나머지는 **더 보기**에 들어갑니다. 프롬프트 모드 버튼은 선택한 텍스트에 그 모드를 실행하고, 복사와 재생 버튼이 있는 패널에 결과를 보여 줍니다.
- 기본 제공 프롬프트 모드로 텍스트를 변환합니다:
  - 쉽고 올바른 영어로
  - 요약(번역 언어로 출력, 기본값은 인터페이스 언어)
  - 음성 정리
- 결과는 생성되는 대로 팝오버에 표시되며, 이후 직전에 포커스가 있던 앱에 삽입하거나 결과의 복사 버튼으로 복사할 수 있습니다.
- 앱에 구애받지 않는, 손쉬운 사용 우선의 선택 텍스트 읽기 경로 하나만 사용합니다. 자동 선택 동작은 먼저 macOS 손쉬운 사용에 선택 내용을 요청하고, **강제 선택**이 허용할 때만 설정된 임시 클립보드 대체 경로를 사용합니다. 각 읽기는 포착한 원본 프로세스에 묶여 있으며, 그 프로세스가 종료되거나 포커스를 잃으면 취소됩니다.
- `Command+C` 시뮬레이션은 기본적으로 꺼져 있습니다. 메뉴의 복사가 여전히 안전한 **강제 선택** 대체 수단입니다. 쓸 만한 복사 메뉴가 없는 앱을 위해 고급 대체 수단으로 복사 시뮬레이션을 명시적으로 켤 수 있지만, 게임, 원격 데스크톱, 가상 머신에 방해가 될 수 있습니다.
- 임시 클립보드 읽기는 하나씩 순서대로 처리되며, 같은 읽기가 관찰한 복사 결과를 여전히 갖고 있을 때만 이전 스냅샷을 복원합니다. 더 새로운 클립보드 내용이 우선합니다. 두 번 복사로 시작하는 방식은 수동적이어서, 사용자가 이미 한 복사를 읽을 뿐 추가 복사를 흉내 내거나 오래된 클립보드 데이터를 복원하지 않습니다. 오른쪽 클릭은 기본 동작 그대로이며 선택 텍스트 읽기를 시작하지 않습니다.
- 브라우저 전용 선택 코드를 사용하지 않으며 브라우저 자동화 권한도 요청하지 않습니다. Chrome, Safari, Edge, 네이티브 앱 모두 같은 범용 경로를 사용합니다.
- 프롬프트 모드, 제공업체, 모델, 사용자 지정 OpenAI 호환 엔드포인트, 시간 제한, 글쓰기 단축키, 받아쓰기 길게 누르기 단축키, 마이크, 복구 모델, 선택 텍스트 번역 언어, 선택 **번역** 프롬프트, 선택 메뉴 버튼, **강제 선택** 모드, 복사 시뮬레이션 허용, AI 발음 음성과 속도를 편집할 수 있습니다.
- 성공한 글쓰기와 선택 결과를 로컬 **기록**에 보여 줍니다. 연속된 중복 항목은 하나로 합쳐지고, 원문과 결과 텍스트를 선택할 수 있으며, 결과 복사와 모두 지우기 기능이 있습니다. 예전 Voice 항목도 계속 읽을 수 있습니다.
- 글쓰기와 번역에 OpenAI, Anthropic, Google Gemini, DeepSeek, Alibaba Qwen, Moonshot Kimi, Zhipu GLM, MiniMax, SiliconFlow, Volcengine Ark, Tencent Hunyuan, Baichuan, 01.AI Yi, xAI, Groq, Mistral, OpenRouter, Perplexity, Together AI, Cerebras, 또는 로컬 모델 서버 같은 사용자 지정 OpenAI 호환 엔드포인트를 사용할 수 있습니다. 발음은 항상 OpenAI를 사용하며, 받아쓰기는 **실시간 받아쓰기**에서 선택한 음성 인식 엔진을 사용합니다.
- 내장 엔진(Qwen3.5 4B 또는 Gemma 4 E4B, Hugging Face에서 한 번만 내려받음)이나 로컬 Ollama 또는 LM Studio 서버로 글쓰기와 번역을 Mac에서 실행합니다. API 키가 필요 없고, 텍스트는 Mac 밖으로 나가지 않습니다.
- 앱 UI를 영어, 중국어 간체, 중국어 번체, 일본어, 한국어, 스페인어, 프랑스어, 독일어, 포르투갈어, 이탈리아어로 제공합니다.
- 작은 선택 메뉴와 설정 및 글쓰기 화면의 공간이 좁은 컨트롤은 번역된 레이블에 맞게 배치를 조정합니다. 언어를 바꾸면 글쓰기 내용을 유지한 채 열려 있는 UI가 새로 고쳐집니다.

## 현재 상태

Inklet은 초기 MVP 단계입니다. 저장소에는 현재 다음이 포함되어 있습니다:

- macOS 앱과 핵심 글쓰기 엔진을 위한 Swift Package.
- 글쓰기 팝오버와 설정 창이 있는 메뉴 막대 앱.
- 제공업체 어댑터와 설정 저장소.
- 핵심 동작에 대한 단위 테스트.
- 수동 테스트 메모: [docs/manual-test-checklist.md](docs/manual-test-checklist.md).

## 요구 사항

- macOS 14 이상.
- Swift 6 툴체인.
- XCTest 지원을 위해 전체 Xcode를 권장합니다.
- Inklet의 손쉬운 사용 권한. 범용 선택 텍스트 읽기, 설정된 복사 대체 경로, 이전 앱으로 포커스 되돌리기, 생성된 결과 붙여 넣기에 필요합니다.
- 단축키를 누르고 있는 동안의 실시간 받아쓰기를 위한 마이크 권한.
- OpenAI 또는 다른 지원 제공업체의 API 키, 또는 로컬 모델. 발음과 OpenAI 엔진을 사용하는 받아쓰기에는 OpenAI API 키가 필요합니다.

## 로컬 모델

Inklet은 Mac에서 실행되는 모델로 글쓰기와 번역을 할 수 있으므로, 텍스트가 Mac 밖으로 나가지 않고 API 키도 필요 없습니다.

- **내장**(Apple 실리콘 전용, 새 설치의 기본값): 제공업체로 **내장**을 선택하고 모델을 고른 다음 **다운로드**를 클릭합니다. 메모리가 16GB 이상인 Mac은 Gemma 4 E4B(약 4.6GB)가 기본값이고, 8GB Mac에는 Qwen3.5 4B(약 2.7GB)를 권장합니다. 새 설치에서는 환영 안내가 모델을 내려받으며, 내려받는 동안 글쓰기 팝오버에 진행 상황이 표시되고, 모델이 아직 없으면 **다운로드** 버튼이 나타납니다. 다운로드는 중단되어도 이어서 받을 수 있으며, 사용 전에 고정된 SHA-256으로 검증됩니다. **내장**을 선택한 상태로 글쓰기 팝오버를 열면, Inklet이 번들된 llama.cpp 서버를 루프백 주소에서만 시작하고 모델을 불러오므로 보통은 요청을 보낼 때쯤 준비가 끝나 있습니다. 메모리가 24GB 이상인 Mac에서는 모델이 계속 로드된 상태로 남아 있다가 macOS 메모리가 부족할 때만 해제되며, 그보다 작은 Mac에서는 5분 동안 사용하지 않으면 서버가 모델을 해제합니다.
- **이 Mac에서 받아쓰기**(Apple 실리콘 전용, 새 설치의 기본값): 실시간 받아쓰기는 Qwen3-ASR 0.6B(약 1GB)로 음성을 인식하며, 30개 언어와 영어가 섞인 중국어를 이해합니다. 같은 번들 llama.cpp 엔진을 별도의 서버로 실행하고, 말하는 동안 약 0.6초마다 다시 받아쓰며, 말을 멈추는 지점에서 문장을 확정합니다. 메모리가 16GB 이상인 Mac에서는 받아쓰기가 켜져 있는 동안 음성 모델을 계속 로드해 두고, 그보다 작은 Mac에서는 글쓰기 팝오버를 열 때 불러와 5분 동안 사용하지 않으면 해제합니다. 받아쓰기를 끄거나 OpenAI를 선택하면 멈춥니다. Inklet이나 macOS가 중국어 번체를 사용하면 중국어 받아쓰기는 번체자로 기록됩니다.
- **Ollama**: [Ollama](https://ollama.com)를 설치하고 `ollama pull qwen3.5:4b`를 실행한 뒤 **Ollama**를 선택합니다. Inklet은 Ollama가 내려받은 모델을 목록으로 보여 줍니다.
- **LM Studio**: LM Studio의 로컬 서버를 포트 1234에서 시작하고 모델을 불러온 뒤 **LM Studio**를 선택합니다.

로컬 제공업체에는 첫 요청이 모델을 불러올 수 있도록 요청당 최소 120초가 주어집니다. Inklet은 로컬 서버에 "생각" 단계를 건너뛰도록 요청하므로, 작은 추론 모델도 바로 답합니다. 소스 빌드는 `scripts/build-llama-server.sh`로 내장 엔진을 컴파일하며 `cmake`가 필요합니다. 없으면 앱은 그대로 실행되고, **내장** 옵션에서 엔진이 포함되지 않았다고 안내합니다.

## 빌드와 실행

앱 번들을 빌드할 때마다 루트 `VERSION` 파일의 `INKLET_VERSION`과 `INKLET_BUILD_NUMBER`를 모두 올리세요. 보통은 패치 버전을 올리고, 큰 변경에는 마이너 또는 메이저 버전을 올립니다. 빌드 번호는 마케팅 버전이 바뀌더라도 지금까지 사용한 모든 빌드 번호보다 큰 양의 정수여야 합니다. 번호를 정하기 전에 최신 `main`, Git 태그, 모든 GitHub 릴리스(초안 포함), 활성 worktree를 확인하세요. Inklet은 이 빌드 번호만으로 업데이트가 더 새로운지 판단합니다.

원격 GitHub DMG 빌드는 `main`에서만 실행합니다. 의도한 변경과 업데이트한 `VERSION`을 병합해 `main`에 푸시한 뒤, `--ref main`으로 `build-dmg.yml`을 실행하세요.

정식 릴리스에서는 빌드 성공과 최종 산출물을 확인하고, 임시 설명을 직전 공개 안정 릴리스 이후의 중국어 및 영어 변경 사항으로 바꾼 다음, 최신 안정 릴리스로 게시합니다. 이미 검증된 초안은 다시 빌드하거나 버전을 바꾸지 않고 게시할 수 있습니다.

DMG 워크플로는 빌드 전에 재사용되었거나 더 낮은 빌드 번호를 검사해 거부하지만, 두 값을 자동으로 올리지는 않습니다. 수동 확인 방법은 [release version checks](scripts/README.md#release-version-checks)를 참고하세요. 패키징된 앱의 버전을 바꾸려면 다시 빌드, 서명, 공증하고 체크섬을 다시 생성해야 합니다. 릴리스 제목이나 파일 이름만 바꾸면 앱은 업데이트되지 않습니다.

저장소 루트에서:

```bash
swift build
scripts/run-local-app.sh
```

일상적인 수동 앱 테스트에는 어느 worktree에서든 `scripts/run-local-app.sh`를 사용하세요. 고정된 `/Applications/Inklet Local.app`으로 설치하고 열기 때문에, macOS 손쉬운 사용 및 키체인 승인을 다시 빌드해도 계속 쓸 수 있습니다.

테스트 실행:

```bash
swift test
```

`XCTest`를 사용할 수 없어 테스트가 실패하면, Command Line Tools만 설치하지 말고 전체 Xcode 앱을 설치하세요.

모든 UI 언어는 `scripts/check-localization.sh`로 확인합니다. `--snapshots`를 추가하면 `.build/localization-audit/` 아래에 합성 데이터로 만든 네이티브 UI의 HTML 갤러리가 생성되며, 명령이 그 경로를 출력합니다. 풀 리퀘스트와 `main` 푸시에서는 전체 단위 테스트와 현지화 검사가 자동으로 실행됩니다. 검사 범위와 남아 있는 수동 확인 항목은 [localization audit](docs/localization-audit.md)를 참고하세요.

## 키보드 흐름

- `Option+Space`: 글쓰기 팝오버를 엽니다.
- `Right Option`: 글쓰기 도우미 원문 편집기가 활성 상태일 때 길게 눌러 받아씁니다. 보조 키를 바꾸거나 받아쓰기를 끄려면 **설정** → **실시간 받아쓰기**로 가세요. 짧게 누르면 아무 일도 일어나지 않습니다.
- 모드 실행기의 `Up` / `Down`: 퍼지 검색 순위로 정렬된 프롬프트 모드 사이에서 강조를 이동합니다.
- 모드 실행기의 `Tab`, `Return`, 숫자 키패드 `Enter`: 강조된 프롬프트 모드를 확정하고 원문 편집기로 포커스를 옮깁니다. 입력기에서 글자를 조합하는 중에는 Return이 글자나 후보를 확정하는 데 쓰입니다. Command, Shift, Option, Control과 함께 누른 Return은 모드를 확정하지 않습니다.
- 편집기의 `Enter`: 원문을 변환하거나, 현재 모드로 생성한 결과를 삽입하거나, 이전 모드로 생성된 오래된 결과를 새로 확정한 모드로 다시 생성합니다.
- `Command+Enter`: 모델을 호출하지 않고 원문을 그대로 삽입합니다.
- `Shift+Command+C`: 팝오버를 닫지 않고 보이는 결과를 복사합니다.
- `Command+Up` / `Command+Down`: 보이는 프롬프트 모드를 차례로 전환합니다.
- `Escape`: 누를 때마다 한 단계씩 뒤로 갑니다. 결과에서 원문 편집기로, 다시 모드 실행기로 돌아간 뒤 팝오버를 닫습니다. 변환 중에 누르면 생성을 멈추고, 부분 결과를 버리고, 편집기에 머뭅니다.
- `Command+,`: Inklet이 활성 상태일 때 설정을 엽니다.

검색은 대소문자와 발음 구별 기호를 구분하지 않으며, 순서대로 이어지는 문자 일치를 지원합니다. 완전 일치와 접두사 일치가 가장 높은 가중치를 받고, 연속된 일치, 단어 시작 부분, 더 앞쪽, 더 촘촘한 일치가 대체로 더 높은 순위를 받습니다.

모드 실행기를 열 때 마지막으로 확정한 프롬프트 모드가 여전히 보이면 그 모드가 강조됩니다. 한 번 클릭하면 모드를 강조하고, 두 번 클릭하면 확정합니다. 실행기로 돌아가도 현재 초안과 결과는 유지됩니다.

## 로컬 저장소와 업그레이드

정식 빌드와 로컬 QA 빌드는 번들 식별자별로 분리된 저장소를 사용하며, 설정, 기록, 번역 캐시, 진단 정보, 키체인 자격 증명을 공유하지 않습니다:

- 정식 빌드 Application Support: `~/Library/Application Support/com.tomwan.inklet/`
- 로컬 빌드 Application Support: `~/Library/Application Support/com.tomwan.inklet.local/`
- 정식 빌드 환경설정: `~/Library/Preferences/com.tomwan.inklet.plist`
- 로컬 빌드 환경설정: `~/Library/Preferences/com.tomwan.inklet.local.plist`
- 제공업체 API 키: 해당 Application Support 폴더의 `api-keys.json`. 사용자 계정만 읽을 수 있고 Time Machine 백업에서 제외됩니다
- 이전 버전이 사용한 키체인 서비스: `Inklet.ProviderAPIKey`(정식)와 `Inklet.Local.ProviderAPIKey`(로컬)

이전 버전은 API 키를 키체인에 보관했습니다. 키가 처음 필요할 때 Inklet은 키체인에서 `api-keys.json`으로 복사하고 키체인 항목은 그대로 두므로, 이전 버전으로 돌아가도 키를 찾을 수 있습니다. 설정에서 키를 바꾸거나 지우면 키체인의 사본도 제거됩니다.

예전 샌드박스 빌드에서 업그레이드한 뒤 처음 실행하면, Inklet은 인식한 예전 환경설정, 제공업체 API 키(해당 키체인 서비스로), 기록을 현재 번들의 저장소로 자동 복사합니다. 원본은 삭제하거나 수정하지 않으므로, 예전 데이터는 롤백이나 복구용으로 남아 있습니다. 버려도 되는 번역 캐시는 이전하지 않습니다.

macOS가 해당 예전 컨테이너에 대한 자동 접근을 막으면, 설정에서 **이전 데이터 가져오기…** 동작을 계속 사용할 수 있습니다. 이 보조 가져오기는 실행 중인 정식 또는 로컬 번들에 맞는 정확한 예전 `Data` 폴더만 확인하고, 현재 파일 패널 권한이 유효한 동안에만 읽으며, 영구 접근 북마크를 저장하지 않습니다.

## 개인정보 보호

- Inklet은 글쓰기와 선택 텍스트 번역 요청을 설정에서 고른 제공업체에 그 제공업체의 API 키로 보냅니다. 발음은 항상 사용자의 OpenAI API 키로 OpenAI를 사용합니다. 받아쓰기는 음성 인식 엔진으로 OpenAI를 선택한 경우에만 OpenAI를 사용합니다.
- 음성 인식에 **이 Mac**을 쓰면, 받아쓰기 오디오와 복구 녹음은 Mac의 서버에서 처리되며 Mac 밖으로 나가지 않습니다.
- 음성 인식에 OpenAI를 쓰면, 받아쓰기 단축키를 누르고 있는 동안 활성 마이크 오디오가 OpenAI Realtime 받아쓰기로 바로 스트리밍됩니다. Inklet은 임시 로컬 복구 녹음도 하나 보관합니다. 이 녹음은 대체 요청이 실제로 시작되기 전까지 로컬에만 있고, 실시간 받아쓰기에 쓰는 기존 OpenAI API 키로 `https://api.openai.com/v1/audio/transcriptions`에 최대 한 번만 업로드되며, 세션이 어떤 식으로 끝나든 삭제됩니다.
- API 키는 제공업체별로 사용자의 Mac에 로컬로 저장됩니다.
- **내장**, Ollama, LM Studio 제공업체를 쓰면 글쓰기와 번역 요청은 Mac의 서버로만 갑니다. 내장 모델을 내려받을 때는 선택한 파일을 위해 Hugging Face에 요청을 한 번 보내며, 이 요청에는 텍스트, 오디오, API 키, 설정이 포함되지 않습니다.
- Inklet은 손쉬운 사용 권한을 범용 선택 텍스트 읽기, 설정된 복사 대체 경로, 이전 앱으로 포커스 되돌리기, 텍스트 붙여 넣기에 사용합니다.
- Inklet은 활성 글쓰기 도우미 원문 편집기에서 받아쓰기를 유효하게 길게 누르는 동안에만 마이크 권한을 사용합니다. 받아쓰기가 끝나면 편집 가능한 초안이 남으며, 다른 앱에 삽입하지 않습니다.
- Inklet은 삽입과 설정된 **강제 선택** 대체 읽기를 위해 클립보드를 잠시 사용합니다. **강제 선택** 읽기는 Inklet이 임시로 복사한 값이 여전히 최신일 때만 이전 클립보드를 복원하며, 이후 외부에서 바뀐 클립보드를 덮어쓰지 않습니다.
- Inklet은 성공한 글쓰기와 선택 동작의 원문과 결과를, 설정에서 지울 때까지 로컬 기록에 저장하며 연속된 중복 항목은 건너뜁니다. 처리하지 않은 받아쓰기 초안은 기록을 만들지 않으며, 예전 Voice 항목은 로컬에서 계속 읽을 수 있습니다.
- 선택 동작은 원본 앱과 선택 위치를 포착하고, 읽기 전과 읽는 동안 원본을 확인한 뒤, 손쉬운 사용으로 현재 선택 내용을 읽습니다. 손쉬운 사용이 선택 텍스트를 돌려주지 않으면, 설정된 **강제 선택** 모드가 메뉴의 복사를 잠시 실행하고 위에서 설명한 보호된 절차로 클립보드 텍스트를 읽을 수 있습니다. `Command+C` 시뮬레이션은 기본적으로 꺼져 있으며, 고급 옵션을 명시적으로 켠 뒤에만 실행됩니다. **강제 선택**은 설정에서 끌 수 있습니다. 이 경로는 브라우저를 대상으로 하는 Apple Events를 보내지 않으며 브라우저 자동화 권한도 요청하지 않습니다. 텍스트를 선택한 뒤 `Command+C`를 빠르게 두 번 누르면, 사용자가 이미 한 복사를 명시적으로 읽습니다. 단지 선택만 한 텍스트는 저장하지 않으며, 성공한 동작이 로컬 기록에 남을 때만 저장됩니다.
- 선택 도우미는 성공한 번역 결과를 해시한 캐시 키로 7일 동안 로컬에 캐시해 반복 번역을 빠르게 합니다.
- 로컬 캐시가 없으면 선택 도우미 번역은 선택한 텍스트와 사용자 지정 **번역** 지침을 선택한 제공업체에 보냅니다. 프롬프트 모드 버튼은 선택한 텍스트와 그 모드의 프롬프트를 선택한 제공업체에 보냅니다. AI 발음은 선택한 텍스트를 OpenAI에 보냅니다.
- Inklet은 `models.dev`에서 공개 모델 카탈로그를 하루에 최대 한 번 가져옵니다. 이 요청에는 텍스트, 오디오, API 키, 앱 설정이 포함되지 않습니다.
- OpenAI나 선택한 제공업체의 데이터 처리 방침을 신뢰하지 않는다면 개인적인 텍스트나 오디오를 보내지 마세요.
