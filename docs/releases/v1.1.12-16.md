# Inklet 1.1.12 (16)

## 中文

相较上一正式版 **1.0.0（4）**，本次 **1.1.12（16）** 主要更新：

- **划词翻译与朗读**：选中文字后可快速翻译、播放原文或译文；支持自定义翻译提示词、语音和语速，翻译结果窗口可调整大小并记住尺寸。
- **Writing 实时听写**：在写作输入框内按住听写快捷键（默认右 Option）即可边说边输入，支持光标处插入、选区替换、麦克风选择及连接异常后的转写恢复；松开完成，Escape 取消并恢复原稿。
- **更顺手的写作流程**：新增模式选择器、模糊搜索和键盘导航，记住上次选择；改善返回编辑、光标滚动与撤销行为。
- **本地历史记录**：查看成功的写作和划词结果，复制结果或清空记录，连续重复内容自动合并。
- **更新检查**：支持菜单手动检查和正式版定期检查；忙于写作、听写或划词时延后提示，更新需自行下载安装。
- **稳定性与隐私**：改进网络中断重试、听写启动及取消、划词关闭与剪贴板恢复；采用统一的辅助功能选区读取路径，无需浏览器自动化权限，模拟复制默认关闭。
- **设置与多语言**：默认写作模型更新为 GPT-5.6 Luna，移除 temperature 设置；完善十种界面的翻译覆盖及紧凑窗口布局。
- **安装与迁移**：统一通过 GitHub 提供签名并经 Apple 公证的 DMG，改进旧沙盒数据迁移与安装校验。

需要 macOS 14 或更新版本及 OpenAI API key。划词与插入使用辅助功能权限；首次有效听写时请求麦克风权限。

## English

Changes since the previous stable release, **1.0.0 (4)**:

- **Selection translation and pronunciation:** translate selected text, play the original or translation, customize the translation prompt, voice and speed, and resize translation windows with remembered dimensions.
- **Realtime dictation in Writing:** hold the dictation shortcut (Right Option by default) to stream text into the source editor. Supports insertion at the caret, selection replacement, microphone selection and transcription recovery after connection failures. Release to finish; Escape cancels and restores the draft.
- **Improved writing workflow:** a mode picker with fuzzy search, keyboard navigation and remembered selection, plus better editor navigation, caret scrolling and undo behavior.
- **Local history:** review successful writing and selection results, copy results or clear history; consecutive duplicates are collapsed.
- **Update checks:** manual menu checks and periodic checks in production builds. Notices wait while you are busy; downloads and installation remain manual.
- **Reliability and privacy:** improved interrupted-request retries, dictation startup and cancellation, selection shutdown and clipboard restoration. A shared Accessibility selection path replaces browser-specific access; browser Automation permission is no longer needed, and simulated copy is off by default.
- **Settings and localization:** GPT-5.6 Luna is the default writing model; the temperature setting has been removed. Improved translation coverage and compact layouts across ten UI languages.
- **Distribution and migration:** signed, Apple-notarized DMGs through GitHub, with improved legacy sandbox data migration and installer verification.

Requires macOS 14 or later and an OpenAI API key. Selection and insertion use Accessibility permission; microphone access is requested on the first valid dictation hold.
